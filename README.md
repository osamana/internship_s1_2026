# Internship 2026 S1 — Course Material

Two tracks share this repository:

- **Full-Stack Web** (FastAPI, PostgreSQL, Next.js)
- **AI Agent Development & Automation** (Python, Claude and other LLM providers, agents, RAG, MCP, automation)

Week 1 is common to both tracks. From week 2 on, open the file for your track.

## How to use each week's file

Work through it top to bottom: learning objectives → theory → reading and videos → labs → deliverables checklist → self-check. Every lab ends with acceptance criteria; the week is done when every box is ticked and reviewed.

If you find a mistake or something unclear in the material, open an issue or a pull request against this repository. Fixing course material counts as real work.
